# 🚆 Journey — Dynamic Railway ETA Prediction

## 📌 Introduction

Journey is an ML-powered railway monitoring and ETA prediction platform designed to provide more dynamic and updated train arrival information.

Traditional railway schedules provide fixed arrival timings, but actual train timings can change due to delays during the journey. Journey addresses this problem by using railway schedule data, station-level information, and delay patterns to predict train delays and calculate a dynamic Estimated Time of Arrival (ETA).

The system combines **Machine Learning, Backend Services, Database Management, and a Web Application** to provide updated train information to users.
